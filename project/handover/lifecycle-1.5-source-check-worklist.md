# Source verification worklist

For a session with network access. Everything below is about public sources only. Every source in this list was previously seen only through search-result summaries (a few were read through a summarising fetch tool), so none of the wording below is confirmed.

## 1. Purpose and method

Purpose: confirm bibliographic facts and check what each source actually says, so that reference entries can be written from pages that were read.

For each source:

1. Open the URL directly (not through search results). Record: **read directly** (yes/no); **date accessed** (the real date of your session); **exact title** as printed on the page or document; **author or organisation** as printed; **URL as finally resolved** (after redirects); **edition, version or publication date** (and last-updated date where shown).
2. Check each listed claim against the source text and answer one of: **SUPPORTED**, **PARTLY** (state what the source actually says), **NOT SUPPORTED**, **NOT FOUND** (source read, statement not present).
3. Quote only from pages you actually read. Never quote or paraphrase search-result wording. Keep quotes short and exact.
4. If a host is unreachable, say so and mark the source "read directly: no". Do not substitute a mirror, cache or archive copy unless you say so explicitly, name the substitute, and mark the result as from a substitute.
5. Where a source is a paywalled standard, record what is freely visible (catalogue page, abstract, preview) and mark claims that need the full text as NOT FOUND (not readable) rather than guessing.

Notes: "key" is either an existing key in `content/references.yml` (marked **existing**) or a drafted new key. All previous access dates (2026-10-06) are to be replaced by your session's date. Where two drafts used different keys for the same source, the key to keep is given.

## 2. Sources, claims and doubts

Claim ids are local to this list (`key#n`). Claims are neutral statements of what the source is cited for.
